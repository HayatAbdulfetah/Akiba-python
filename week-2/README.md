# Week 2 — Conditions, Loops & Problem Solving 🐍

This folder contains my Python practice exercises and mini-project from Week 2 of the **AKIBA TECHNOLOGIES Software Engineering & Backend Bootcamp**. This week's focus was on making decisions in code, repeating operations, and solving problems step by step.

## 📚 Topics Covered

- Conditional statements (`if`, `elif`, `else`)
- Comparison and logical operators
- `for` and `while` loops
- Modulus operator (`%`)
- Random number generation
- Counters and accumulators
- Input validation and edge cases
- Computational thinking

## 📝 Practice Tasks

### Task 1 — Even or Odd
Checks whether a user-provided number is even or odd.

### Task 2 — Largest of Three
Compares three numbers and identifies the largest, including cases where some or all values are equal.

### Task 3 — Prime Number Checker
Uses a loop to check whether a number is prime, including special cases such as 0, 1, and 2.

### Task 4 — Palindrome Checker
Determines whether a word reads the same forward and backward, regardless of letter case.

### Task 5 — Sum of Digits
Calculates the sum of a number's digits using a loop.

### Task 6 — FizzBuzz
Prints a sequence of numbers, replacing multiples of 3 with `Fizz`, multiples of 5 with `Buzz`, and multiples of both with `FizzBuzz`.

### Task 7 — Number Guessing Game
Creates a guessing game in which the user receives hints indicating whether a guess is too high or too low.

### Task 8 — Count Numbers
Uses loops and conditions to process numbers and count values according to the exercise requirements.

### Task 9 — ATM PIN System
Simulates PIN verification and handles incorrect attempts according to the program's rules.

### Task 10 — Number Analyzer
Uses conditions and loops to examine numbers and determine their relevant properties.

## 🚀 Mini-Project — Simple Bank Account System

A menu-based banking application that lets users check their balance, deposit money, and withdraw money.

The program starts with a balance of **1,000 Birr** and includes PIN verification and handling for invalid menu selections.
