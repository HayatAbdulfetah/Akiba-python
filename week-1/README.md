# Week 1 — Python Fundamentals 🐍

This folder contains my Python exercises and mini-project from Week 1 of the **AKIBA TECHNOLOGIES Software Engineering & Backend Bootcamp**. The focus was on learning Python basics and applying them to simple, practical problems.

## 📚 Topics Covered

- Variables and data types
- Strings and basic text operations
- User input and output
- Type conversion
- Arithmetic and comparison operators
- Formatted output
- Basic Python syntax and program structure
- Git and GitHub fundamentals

## 📝 Practice Tasks

### Task 1 — Personal Introduction
A program that asks for personal details and displays an introduction.

### Task 2 — Student ID Card
Collects student information and presents it in a simple ID card format.

### Task 3 — Rectangle Calculator
Uses the given length and width to calculate the area and perimeter of a rectangle.

### Task 4 — Temperature Converter
Converts a temperature from Celsius to Fahrenheit.

### Task 5 — Shopping Receipt
Calculates the cost of purchased items using their prices and quantities.

### Task 6 — Employee Salary Calculator
Calculates gross salary by combining basic salary and allowances.

### Task 7 — Travel Time Calculator
Estimates travel duration using distance and average speed.

### Task 8 — Exam Score Calculator
Accepts scores from different subjects and calculates the average.

### Task 9 — Currency Converter
Converts an amount in US dollars to Ethiopian Birr using a specified exchange rate.

### Task 10 — BMI Calculator
Calculates Body Mass Index using a person's weight and height.

## 🚀 Mini-Project — Student Profile System

A beginner-friendly application that gathers and displays a student's personal, academic, and contact details. This project brings together the Python concepts practiced throughout the week.
